# Видео-заставка

Положите сюда исходный ролик под именем:

    intro.mp4

Требования из ТЗ (п.18) — уточнить у заказчика: разрешение, кодек.
Рекомендация для веб/офлайн-плеера: H.264 + AAC в контейнере mp4 —
воспроизводится нативным тегом <video> без дополнительных библиотек.

Если файла нет — экран заставки автоматически пропускается, приложение
сразу открывает карту.
