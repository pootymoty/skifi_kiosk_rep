# Тексты

Сейчас тексты объектов редактируются прямо в js/data/content.js
(поле sections каждого объекта — название блока + текст). Это самый
простой способ для небольшого числа объектов.

Если текстов станет много и захочется хранить их отдельно от кода —
можно класть сюда .json/.txt файлы и заменить статический импорт
CONTENT в js/app.js на fetch() этих файлов (потребует запуска через
локальный HTTP-сервер, т.к. fetch() файлов по file:// блокируется
браузером — при открытии index.html напрямую двойным кликом это
работать не будет).
