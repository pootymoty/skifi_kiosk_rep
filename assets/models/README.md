# 3D-модели

Ожидаемые файлы (формат .glb, ТЗ п.18):

    panther.glb          — экран «Скифский звериный стиль» (ячейка 1 из 3)
    deer.glb             — экран «Скифский звериный стиль» (ячейка 2 из 3)
    panther-deer.glb     — экран «Скифский звериный стиль» (ячейка 3 из 3, составная сцена — пантера и олень вместе)
    human.glb            — экран «Человек»

Желательно (ТЗ п.18): модель оптимизирована, известно количество
полигонов и размер файла — это влияет на скорость загрузки на самом
киоске. Особенно важно для трёх моделей на одном экране («Скифский
звериный стиль») — там втрое больше данных грузится/рендерится
одновременно, чем для одиночной модели.

Пока файла нет (или пока не подключён Three.js, см. js/vendor/README.md)
— вместо модели показывается временная геометрия с подписью, какой файл
нужно добавить (для экрана из трёх моделей — в каждой ячейке отдельно).
