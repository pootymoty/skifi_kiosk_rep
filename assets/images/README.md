# Изображения

Ожидаемые файлы (пути заданы в js/data/content.js — можно переименовать
там же, если удобнее):

    map.jpg                    — основная картинка карты (ТЗ п.18 «Карта»)
    carpet.jpg                 — изображение ковра для 2D-режима (ТЗ п.13)
    carpet-hole-restored.jpg   — тот же ковёр целиком, но с восстановленным
                                  повреждённым участком (для интерактивной
                                  зоны «дырки», см. content.js → carpet.hole)
    authors-qr.png             — QR-код (предположительно на Telegram-канал, ТЗ п.15)

Важно про `carpet-hole-restored.jpg`: это должна быть **та же по кадру
картинка**, что и `carpet.jpg` (тот же ракурс/масштаб/обрезка), просто
с восстановленным участком — код делает между ними плавный кросс-фейд
поверх одного и того же приближения, и если рамки не совпадут, будет
заметный «скачок» картинки в момент показа.

Координаты самой «дырки» (`hole.x` / `hole.y` в `content.js`, в
процентах от размеров `carpet.jpg`) сейчас стоят примерные —
после того как оба файла будут на месте, откройте макет и подвиньте
эти проценты, чтобы метка легла точно на повреждённый участок.

Пока файла нет — на соответствующем месте показывается декоративная
заглушка с подписью, какой файл нужно добавить.
