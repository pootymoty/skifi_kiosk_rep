# Шрифты

Используются два шрифта из макета Figma — оба должны быть офлайн-файлами
(на площадке нет интернета, Google Fonts CDN не подойдёт):

    stalinist-one.woff2   — крупные заголовки ("ДРЕВНИЕ", "СКИФЫ" и т.п.)
    geologica-light.woff2 — весь остальной текст (кнопки, подписи, эйбрау),
                            начертание Light (font-weight: 300)

Положите файлы сюда с этими именами (или другими — тогда поправьте пути
в css/style.css → секция @font-face в самом начале файла) в формате
.woff2 (либо .woff/.ttf — тогда добавьте свою строку format() рядом).

Пока файлов нет — используется системный шрифт-заменитель (обычный
serif/sans), макет не ломается, просто выглядит без авторского шрифта.
